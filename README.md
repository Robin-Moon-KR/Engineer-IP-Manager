Engineer IP Manager is a utility program designed to eliminate the hassle for IT and Systems Integration (SI) engineers of having to repeatedly reconfigure their IP addresses to match various equipment.

It allows users to store and manage IP information (such as site, room, and equipment name) and easily locate entries using Initial Consonant Search (Chosung search) for intuitive network configuration.

Once your work is complete, you can instantly revert your settings to DHCP with a single action.

It supports exporting your data to an Excel file.

You can also import updated or newly added information back into the program using the modified Excel file.
